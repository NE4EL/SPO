# АвтоСервис — Система управления СТО

Веб-приложение для автоматизации работы автосервиса: учёт заказов, склад запчастей, база автомобилей. Курсовой проект.

## Быстрый старт

```bash
npm install
npm run dev
```

Откроется на **http://localhost:5173**
